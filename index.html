what we are learning

The basics
behind every page.

Every project starts with a few simple ideas. These are the three tools we are getting to know.

01</>

the structure

HTML

The parts of a page: headings, paragraphs, images, links, and everything that gives content its place.

02✦

the style

CSS

The colours, spacing, layout, and personality that turn a plain page into something that feels like ours.

03{ }

the action

JavaScript

The clicks, changes, and interactions that help a page respond when someone uses it.

where a website lives

Hosting makes
the page public.

A hosting service stores a website's files on a server and delivers them to people when they visit its web address.

01 →

Store

HTML, CSS, JavaScript, images, and other assets are kept on a server that stays connected to the internet.

02 →

Connect

A domain name gives visitors an easy address, while DNS connects that address to the hosting server.

03

Serve

When someone opens the site, the host sends the right files to their browser so the page can load and work.
